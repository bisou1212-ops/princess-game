## 0. 기기 정보 (점검 화면에서)
- [ ] 기기 이름·브라우저: ______
- [ ] fps (마당에서 걸어 다닐 때): ______ (30 이상이면 좋음)
- [ ] 자동 조절 단계: __/4 (높을수록 기기가 느려서 그래픽을 낮춘 것)
- [ ] 고른 한국어 음성: ______ ("없음"이면 기기 설정 › 텍스트 음성 변환에서 한국어 음성 설치)

## 1. 시작
- [ ] 홈 화면에 추가(앱처럼 설치)가 되고, 아이콘으로 열린다
- [ ] 처음 켜면 펫 고르기가 나온다 (이미 골랐으면 마당)
- [ ] 화면을 처음 톡하면 오르골 음악이 들린다
- [ ] 가로·세로로 돌려도 화면이 맞춰진다

## 2. 목소리 (가장 중요)
- [ ] 대사가 **한국어 목소리**로 읽힌다
- [ ] "Apple!", "Pink!" 같은 영어는 영어 목소리로 읽힌다
- [ ] 읽는 단어가 빛나며 따라간다
- [ ] 말하는 동안 음악이 작아진다
- [ ] 너무 빠르거나 느리면 → 부모 설정 › 말 빠르기

## 3. 터치·움직임
- [ ] 바닥을 톡하면 공주가 걸어간다 (손가락이 조금 미끄러져도)
- [ ] 친구·꽃·문을 톡하면 걸어가서 말 걸기·줍기·들어가기
- [ ] 걸을 때 화면이 뚝뚝 끊기지 않는다
- [ ] 펫이 따라오고, 펫을 톡하면 말한다
- [ ] 그림을 길게 눌러도 "이미지 저장" 메뉴가 뜨지 않는다
- [ ] 가게·옷장 목록을 끌어도 페이지가 새로고침되지 않는다

## 4. 놀이 한 바퀴
- [ ] 친구 부탁 받기 → 꽃 모으기(하나! 둘! 소리) → 선물·별사탕
- [ ] 드레스룸에서 옷 바꾸기 (반짝 소리)
- [ ] 성 문 → 방에서 가구 끌어다 놓기·돌리기·색 바꾸기
- [ ] 지도 → 꽃 왕국 날아가기 → 별사탕 가게에서 사기
- [ ] 펫 밥 주기(간식 세기), 목욕(손가락으로 문지르기)
- [ ] 삐삐 위로하기(기분 카드 고르기)

## 5. 부모 설정
- [ ] 마당 오른쪽 아래 작은 톱니 → 곱셈 → 설정이 열린다
- [ ] 소리 끄기·켜기, 말 빠르기, 그래픽 품질이 바뀐다
- [ ] 플레이 시간 10분 → 8분쯤 펫이 "곧 자러 갈 시간" → 10분에 잠자리 장면
- [ ] 잠자리 장면에서 톱니 → 곱셈 → "10분 더"로 다시 놀 수 있다
- [ ] (마지막에) 처음부터 하기 → 저장이 지워지고 펫 고르기부터

## 6. 오래 놀기
- [ ] 20분 넘게 놀아도 느려지거나 꺼지지 않는다
- [ ] 태블릿이 많이 뜨거워지지 않는다 (뜨거우면 그래픽 품질 "가볍게")
- [ ] 앱을 내렸다 다시 열면 이어서 된다 (옷·가구·별사탕 유지)
