## 1. 게임 개요

7세 여자아이가 공주가 되어 자유롭게 돌아다니고, 성과 옷을 꾸미고, 친구들과 어울리며 자연스럽게 배우는 3D 롤플레잉 게임.

| 항목 | 내용 |
| --- | --- |
| 장르 | 자유도 높은 공주 컨셉 롤플레잉 + 꾸미기 |
| 주 대상 | 7세 여자아이 (글을 다 읽지 못해도 플레이 가능해야 함) |
| 핵심 요소 | 성 꾸미기, 옷 꾸미기, 여러 캐릭터, 자유 탐험, 교육 효과 |
| 그래픽 | 동글동글한 치비 3D, 파스텔 + 반짝임 |
| 플랫폼 | 웹 브라우저 (태블릿·폰·PC), PWA로 홈 화면 설치 |
| 기술 스택 | Three.js + Vite + TypeScript, Rapier(필요 시) |
| 개발 방식 | Claude Code, Claude 외 모든 툴 무료 |
| 배포 | Cloudflare Pages(게임 파일), 필요 시 GCP e2-micro VM(서버 기능) |
| 수익 모델 | 없음 — 광고·결제 없는 가족용 게임 |

**성공 기준**: 아이가 도움 없이 15분 동안 즐겁게 놀고, 스스로 다시 켜고 싶어 한다.

## 2. 세계관과 스토리

공주는 자기 성을 중심으로 네 개의 왕국을 여행하며 친구를 사귀고, 부탁을 들어주고, 각 왕국의 옷과 장식을 모읍니다.

| 왕국 | 분위기 | 모을 수 있는 것 | 배울 거리 | 버전 |
| --- | --- | --- | --- | --- |
| 내 성 (중심) | 아이만의 집, 처음엔 텅 빈 성 | 모은 장식을 배치 | 정리정돈, 공간 꾸미기 | MVP |
| 꽃 왕국 | 봄, 꽃밭·나비·동물 친구 | 꽃 드레스, 정원 장식 | 색깔·꽃 이름(한글·영어) | MVP |
| 바다 왕국 | 여름, 바닷가·인어 친구 | 조개 액세서리, 바다 소품 | 수 세기, 바다 동물 | 이후 |
| 눈 왕국 | 겨울, 눈사람·펭귄 친구 | 반짝이 드레스, 겨울 장식 | 모양·패턴 맞추기 | 이후 |
| 하늘 왕국 | 구름 위, 페가수스·별 | 별·무지개 아이템 | 비행, 날씨·하늘 | 이후 |

**기본 이야기**: 공주가 새 성에 이사와서, 여러 왕국 친구들과 우정을 쌓고 성을 멋지게 채워가는 이야기.
**원칙**: 악당·싸움·실패 패널티 없음.

## 3. 캐릭터

주인공은 아이가 만드는 나만의 공주. 골라서 키우는 펫 한 마리가 항상 함께합니다. (이름·성격은 가제)

| 캐릭터 | 역할 | 부탁 예시 | 교육 연결 |
| --- | --- | --- | --- |
| 나만의 공주 | 주인공 — 얼굴·머리·피부·눈 색 선택, 이름 짓기 | — | — |
| 펫 (유니콘·고양이·강아지 중 선택) | 따라다니며 힌트, 밥·목욕·옷 | "배고파요!" | 돌봄, 생활습관 |
| 플로라 공주 | 꽃 왕국의 공주, 첫 친구이자 안내역 | 파티 초대장 전해주기 | 낱말 읽기, 인사 예절 |
| 토리 (꽃집 토끼) | 꽃집 주인 | 빨간 꽃 3송이 모아오기 | 색깔(한글·영어), 수 세기 |
| 도치 (요리사 고슴도치) | 빵집 주인 | 케이크에 딸기 5개 올리기 | 숫자·더하기 |
| 고고 (정원사 곰) | 무뚝뚝하지만 다정한 정원사 | 엎힌 화분 정리하기 | 정리정돈, 순서 |
| 삐삐 (음악가 새) | 부끄럼이 많은 가수 | 우는 친구 위로하기 | 감정 알아차리기, 배려 |

## 4. 핵심 플레이 루프

한 번 플레이(약 15~20분) = **돌아다니기 → 부탁 들어주기 → 선물 받기 → 꾸미기 → 친구에게 자랑하기**. 어느 단계든 건너뛰고 마음대로 놀 수 있습니다.

1. **성에서 시작** — 펫이 반기고, 펫 돌보기(밥·목욕)로 하루를 연다.
2. **옷 고르기** — 드레스룸에서 오늘 입을 옷을 조합한다.
3. **꽃 왕국으로 이동** — 지도에서 톡, 탈것을 타고 날아간다(짧은 연출).
4. **친구들의 부탁** — 머리 위에 ♥ 표시가 있는 친구를 톡하면 1~3분짜리 부탁을 받는다.
5. **선물과 별사탕** — 부탁을 해결하면 옷·가구 선물과 별사탕을 받고, 가게에서 살 수도 있다.
6. **성 꾸미기** — 새 가구로 방을 꾸민다.
7. **친구 초대·사진** — 친구를 성에 초대하면 칭찬해 주고, 기념사진을 앨범에 남긴다.
8. **자연스러운 마무리** — 부모가 정한 시간이 되면 공주와 펫이 잠자리에 드는 장면으로 끝난다.

**원칙**: 실패·시간 제한·점수 경쟁 없음. 틀려도 친구가 "다시 해볼까?" 하며 힌트를 준다.

## 5. 꾸미기 시스템

### 5.1 옷 꾸미기 — 부위별 조합 + 색 바꾸기

- 부위: 머리 모양, 왕관·머리띠, 드레스(상의+치마 또는 원피스), 신발, 액세서리(목걸이·날개·마법봉)
- 각 아이템은 색 8개 중 선택 — 아이템 10개만으로도 수백 가지 조합
- 거울 화면에서 공주가 빙글 돌며 포즈, 사진 찍기로 저장
- 펫 옷(리본·모자)은 다음 버전

### 5.2 성 꾸미기 — 방별 가구 배치

- MVP 방: 침실, 드레스룸, 파티홀 (3개)
- 가구를 끌어다 놓고, 톡하면 돌리기·색 바꾸기·치우기
- 벽지·바닥·커튼 색 변경
- 친구를 초대하면 꾸민 방에서 반응("우와, 예쁘다!") — 꾸미기의 보상

### 5.3 아이템 얻기

- 친구 부탁 해결 → 특별한 옷·가구 선물 + 별사탕
- 별사탕으로 꽃 왕국 가게에서 기본 아이템 구입 (동전 세기·셈 연습)
- 실제 돈 결제 없음. 별사탕이 모자라 못 사는 스트레스가 없도록 넉넉하게 지급

## 6. 교육 요소

배움은 문제 풀이 화면이 아니라 친구의 부탁과 꾸미기 안에 녹아 있다. 아이는 "공부한다"는 느낌 없이 반복해서 접한다.

| 영역 | 게임 속 모습 | 난이도 조절 |
| --- | --- | --- |
| 한글 낱말 | 모든 대사를 음성으로 읽어주며 단어 강조, 간판·초대장 읽기, "'꽃'을 찾아줘" | 그림+글자 → 글자만 점점 늘리기 |
| 숫자·셈 | 꽃 3송이 모으기, 딸기 개수 맞추기, 별사탕 세어서 내기 | 1~5 → 1~10 → 더하기 |
| 영어 단어 | 옷·가구·색을 톡 누르면 한글과 영어로 함께 읽어줌 ("Pink! 분홍!") | 색깔 → 옷 → 동물·사물 |
| 감정·배려 | 우는 친구 표정 보고 기분 고르기, 위로하기·양보하기 선택 | 기본 감정 4개(기쁨·슬픔·화남·무서움)부터 |
| 생활습관 | 펫 밥·목욕 챙기기, 엎힌 물건 제자리 정리, 자기 전 양치 | — |

난이도는 아이가 맞히는 비율에 따라 자동으로 조금씩 올라가고, 부모 설정에서 직접 정할 수도 있다.

## 7. 조작법과 UI

모든 조작은 **"톡"과 "끌기"** 두 가지뿐. 글을 못 읽어도 그림과 음성만으로 플레이할 수 있어야 한다.

| 하고 싶은 것 | 조작 |
| --- | --- |
| 걸어가기 | 가고 싶은 바닥을 톡 → 공주가 알아서 걸어감 (길찾기) |
| 친구·물건과 대화 | 친구나 물건을 톡 → 걸어가서 말을 걸거나 줍기 |
| 대사 넘기기 | 말풍선 아무 곳이나 톡, 다시 듣기는 스피커 아이콘 |
| 옷 입기 | 아이템 톡 → 바로 입힘, 색 동그라미 톡 → 색 변경 |
| 가구 배치 | 아래 서랍에서 끌어다 놓기, 톡하면 돌리기·색·치우기 버튼 |
| 카메라 | 두 손가락으로 돌리기·확대 (안 해도 플레이 가능) |

**UI 원칙**

- 버튼 최소 64px, 화면 가장자리에 크게만 배치
- 고정 아이콘 4개: 지도, 드레스룸(옷), 가방(선물·별사탕), 앨범(사진)
- 모든 대사는 글자 + 음성, 읽는 단어에 맞춰 글자가 빛남
- 다음에 할 일은 반짝이는 표시와 펫의 힌트로 안내
- 빨간색 경고·실패 소리 없음, 모든 행동에 긍정적인 반응
- 부모 설정은 어른용 잠금 뒤에 (예: 간단한 곱셈 문제)

## 8. 아트·사운드 방향

### 8.1 그래픽

- 캐릭터: 2~3등신 치비, 큰 눈과 부드러운 곡선, 매끄러운 재질 (동물 친구도 같은 비율)
- 색: 분홍·라벤더·민트·크림 중심, 반짝이 파티클·부드러운 빛번짐(bloom)
- 기술: 툰 셰이딩 + 연한 외곽선, 그림자는 Blender에서 미리 구워(bake) 폰에서도 가볍게
- 제작: Blender MCP로 모델링, 옷·머리는 부위별로 따로 만들어 갈아끼우는 구조, 색 바꾸기는 코드에서 재질 색만 변경
- 애니메이션: 걷기·손 흔들기·빙글 돌기·박수 등 기본 동작 위주

### 8.2 사운드

- 대사: 브라우저 내장 음성(Web Speech API) — 캐릭터마다 목소리 높낮이(pitch)·속도(rate)를 다르게 해서 구분
- 확인 필요: 아이가 쓸 태블릿·폰에 한국어·영어 음성이 설치돼 있는지, 목소리가 괜찮은지 프로토타입 단계에서 먼저 확인
- 효과음: 반짝이·방울·박수 같은 밝은 소리 (CC0 효과음 + jsfxr)
- 배경음: 오르골·하프 중심의 잔잔한 CC0 음악, 장소마다 다른 곡

## 9. 아이 안전·부모 설정

가족용 게임이므로 광고·결제·외부 링크·채팅이 없고, 플레이 시간은 부모가 정한다.

- [ ] **플레이 시간**: 부모가 10/15/20/30분 중 설정, 2분 전에 펫이 "곧 자러 갈 시간이에요" 예고, 시간이 되면 잠자리 장면으로 마무리
- [ ] **어른용 잠금**: 부모 설정·저장 초기화는 간단한 문제를 풀어야 열림
- [ ] **광고·결제·외부 링크 없음**, 로그인·채팅 없음
- [ ] **저장**: 기기 안에 자동 저장(localStorage/IndexedDB), 개인정보는 공주 이름 외에 수집하지 않음
- [ ] **학습 기록(부모용)**: 오늘 배운 낱말·숫자·영어 단어를 부모 화면에서 확인 (다음 버전)
- [ ] **눈 보호**: 화면 밝기 급변·깜빡임 없음, 부드러운 색감

## 10. 개발 범위와 일정

첫 버전(MVP)은 **내 성 + 꽃 왕국** 하나로, 약 2~3개월(퇴근 후 하루 1~2시간) 안에 아이가 실제로 해볼 수 있게 만든다. 아이의 반응을 보고 다음 왕국을 추가한다.

| 구분 | MVP에 넣음 | 나중에 |
| --- | --- | --- |
| 장소 | 내 성, 꽃 왕국, 왕국 지도 | 바다·눈·하늘 왕국 |
| 캐릭터 | 나만의 공주 만들기, 펫 1마리 선택, 꽃 왕국 친구 5명 | 왕국별 친구, 펫 종류 추가 |
| 꾸미기 | 옷 꾸미기, 성 방 3개 꾸미기 | 성 외부·정원, 펫 옷 |
| 교육 | 부탁 안에 낱말·숫자·영어·배려 녹이기 | 부모용 학습 기록 |
| 이동 | 지도 터치 + 날아가는 연출 | 직접 날기 미니게임 |
| 저장 | 기기 안 자동 저장 | GCP VM으로 기기 간 이어하기 |

### 10.1 개발 마일스톤 (Claude Code 작업 순서)

| # | 마일스톤 | 완료 기준 |
| --- | --- | --- |
| M0 | 프로젝트 세팅 | Vite + TS + Three.js 빈 씬이 폰 브라우저에서 뜸, GitHub → Cloudflare Pages 자동 배포 |
| M1 | 그레이박스 이동 | 회색 도형으로 만든 성 마당에서 바닥 톡 → 캐릭터가 걸어감 (길찾기) |
| M2 | 대화·음성 | 친구(도형) 톡 → 말풍선 + TTS 읽기, 단어 강조 |
| M3 | 부탁 시스템 | 부탁 데이터(JSON)로 "꽃 3송이 모으기" 1개 완성, 선물 지급 |
| M4 | 옷 꾸미기 | 부위별 교체 + 색 변경, 저장/불러오기 |
| M5 | 성 꾸미기 | 방 1개에 가구 끌어다 놓기·돌리기·색 변경 |
| M6 | 지도·이동 연출 | 성 ↔ 꽃 왕국 이동, 로딩 화면 |
| M7 | 아트 교체 | 치비 공주·펫·친구 모델, 툰 셰이딩, 파스텔 환경 |
| M8 | 콘텐츠 채우기 | 친구 5명 부탁 각 2~3개, 방 3개, 아이템 30개+ |
| M9 | 부모 설정·마감 | 플레이 시간, 잠금, 사운드, 실기기 테스트 |
