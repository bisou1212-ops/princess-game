# 그래픽 고도화 — STEP 1 분석 · STEP 2 설계

M8-5(펫) 전에 진행. 그래픽 개선이 끝나면 M8-5로 돌아간다.
기준: 실제 파일과 실행 화면을 측정한 결과 (2026-11-24, 커밋 93e3d7f).

## STEP 1. 현재 프로젝트 분석

### 엔진·렌더링
- Three.js r187, WebGL2, 직접 만든 장면 구조 (게임 엔진 없음). Vite + TypeScript.
- 화풍 "부드러운 입체": 물리 재질(MeshPhysicalMaterial: 피부·머리·옷·보석·기본) + 반짝이 가루·머리 그라데이션 셰이더(`src/core/toon.ts`), 주변 반사(RoomEnvironment PMREM) + 빛번짐(UnrealBloom) + Neutral 톤 매핑(`src/core/look.ts`).
- 실시간 그림자: 방향광 1개, 1024 그림자 맵. 외곽선 끔. 안개 있음.

### Blender 연동
- `scripts/blender/build_princess.py`·`build_friends.py`가 구·원뿔·도넛 도형을 붙여 부위별 물체를 만든다 → `src/assets/models/*.glb`.
- 측정: princess.glb 0.8MB, 물체 21개(부위·옷), 삼각형 42,596 / friends.glb 0.7MB, 친구 5명, 삼각형 38,600.
- **UV 없음, 텍스처 없음, 뼈대(skin) 없음, 애니메이션 클립 없음.** 재질 이름(tint 등)으로 게임에서 색만 바꾼다.

### 캐릭터 모델링
- 치비 비율(머리 크게), 반짝이는 그림 눈(평면 그림 `anime-eyes.ts`), 볼·입은 작은 도형.
- 몸은 구(머리) + 원뿔(드레스)이 맞닿은 형태. 팔은 캡슐, 손은 구, 손가락 없음. 목·어깨 연결부가 도형 이음새 그대로.
- 눈썹·코 없음. 표정 바꾸기 없음(눈물만 따로 붙임).

### 리깅·애니메이션
- **뼈대·애니메이션 없음.** 걷기 = 몸 전체가 위아래로 통통(sin), 몸 방향은 이동 방향으로 회전. 팔다리·머리·치마는 움직이지 않는다 → "인형이 미끄러지는" 느낌의 가장 큰 원인.
- 연출: 옷 바꾸면 빙글+폴짝, 거울 앞에서 좌우로 몸 돌리기.

### 배경
- `src/data/*.json` 배치 데이터 → 코드로 도형 생성(`props.ts`): 성벽=상자, 탑=원기둥+고깔, 집=상자+사각뿔 지붕, 나무=원기둥+구 2개, 꽃밭=작은 꽃 도형.
- 땅은 평평한 판 2장(바깥·마당), 높낮이 없음. 텍스처·AO 없음. 하늘은 그라데이션 + 안개, 구름 없음. 분수는 원기둥(물 없음).
- 측정: 성 마당 메시 198개 / 삼각형 66,708 / 재질 137개, 꽃 왕국 메시 275개 / 삼각형 72,836.

### 카메라·조작
- 조작: 톡한 곳으로 격자 A* 길찾기 후 걷기(`walker.ts`). 속도 3m/s로 바로 출발·바로 정지(가속·감속 없음), 회전 10rad/s.
- 카메라: 위 뒤쪽 고정 거리(0, 9, 9)에서 부드럽게 따라감, 세로 화면이면 조금 뒤로. 거울·대화 때 시점 이동.

### 품질 저하 원인 (영향 큰 순서)
1. 뼈대·애니메이션이 없어 몸이 굳은 채 미끄러진다 (걷기·멈추기·말하기 모두 같은 자세).
2. 캐릭터가 도형을 붙인 모양 그대로라 이음새(목·어깨·손·발)가 어색하다.
3. 배경이 단순 도형 나열, 땅이 평평, 재질이 모두 같은 질감이라 깊이감이 없다.
4. 움직임에 가속·감속·기울기·발 박자가 없다.
5. 메시·재질 수가 많아(최대 275개) 그리기 호출이 많다 → 화질을 더 올릴 여유를 먼저 만들어야 한다.

## 프롬프트 항목 중 이 게임에 맞지 않는 것 (CLAUDE.md·GDD 기준)
대상이 7세, 조작은 **톡·끌기만**, 실패·벌점 없음, 중급 안드로이드 태블릿 30fps·화면 삼각형 10만·첫 로딩 10MB.
- **넣지 않음:** 달리기 버튼·전력 질주·점프 버튼·더블 점프·웅크리기·슬라이드·벽 타기·수영·피격/넉백, 가상 조이스틱, 날씨·밤낮 순환(나중에 검토), 카메라 충돌(위에서 내려다보는 시점이라 가릴 물체 없음).
- **바꿔서 넣음:** 점프 → 기쁠 때 "폴짝", 착지 반동·먼지. 달리기 → 먼 곳을 톡하면 자연스럽게 빨라지는 걸음. 360도 자유 이동 → 톡 이동 + "누르고 끌면 그 방향으로 계속 걷기".
- **텍스처:** 고해상도 사진 텍스처 대신 버텍스 컬러 + 구운 AO(용량 0에 가깝고 파스텔 화풍과 맞음).

## STEP 3 결과 (시범 제작, 브랜치 `graphics-pilot`)

### 공주
- 몸 다듬기: 어깨 이음새, 엄지 있는 손, 발, 눈썹, 작은 코 (`build_princess.py`).
- 뼈대 14개(`Rig`): 골반·척추·머리·뒷머리·치마·팔/손·다리/발. 옷 21벌 모두 같은 뼈대에 붙음(SkinnedMesh). 드레스·가방끈은 높이에 따라 골반·척추·치마에 부드럽게 나눔.
- 동작 클립 4개(`anim_princess.py`): 가만히(숨쉬기·두리번), 걷기(16프레임 두 걸음, 발끝·팔·골반 통통·몸 비틀기), 폴짝(웅크림→점프→착지 반동), 손 흔들기.
- 게임(`princess-animator.ts`): 속도로 가만히↔걷기 섞기 + 걷기 재생 속도=이동 속도, 폴짝·손 흔들기 섞어 재생, 말하는 친구 바라보기, 회전할 때 안쪽으로 기울기, 출발·멈춤 때 앞뒤 기울기, 뒷머리·치마 스프링 출렁임, 눈 깜빡임. 그림 눈은 머리 뼈에 붙음.
- 이동(`walker.ts`): 가속·감속(7m/s²), 먼 곳은 1.3배 빠른 걸음.
- 연결: 옷 바꾸면 폴짝+빙글, 친구에게 가면 손 흔들며 바라봄.

### 성 마당 배경 (`build_castle_env.py` → `env-castle.glb`)
- 본성(돌 띠·아치 창문·발코니·가운데 지붕·성가퀴), 탑(창문·성가퀴·고깔 지붕·깃발), 성벽+모퉁이 작은 탑, 낮은 문기둥, 2단 분수 + 일렁이는 물 셰이더, 잎 덩어리 나무, 덤불, 돌 테두리 꽃밭, 나무 벤치, 가로등, 징검돌 길, 성 밖 언덕·나무.
- 버텍스 컬러 AO(거리 1.2m, 재질별 세기), 재질별로 합쳐 16개 물체.
- 충돌·길찾기는 courtyard.json 그대로. 모델을 못 불러오면 예전 도형 배경.

## STEP 4·5 결과 (확대 적용 + 통합 확인)

- 친구 5명: 몸에 맞춘 뼈대(공주와 같은 뼈 이름 + 동물은 귀·꼬리), 같은 4개 동작. 파일 `friend-<id>.glb`(합계 1.4MB). 마당에서 걷기·멈추기·공주 바라보기·말 걸면 손 흔들기, 방에 초대하면 폴짝.

- 효과: 발걸음 먼지, 폴짝 착지 먼지, 꽃잎(인스턴싱), 구름(구름 하나 = 메시 하나), 잎·산울타리 바람 흔들림(셰이더).
